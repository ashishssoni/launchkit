# LaunchKit Web

A lightweight Next.js frontend demo for the LaunchKit SaaS backend.

## Pages
- `/` marketing / landing page
- `/login`
- `/register`
- `/dashboard`
- `/billing`
- `/api-keys`
- `/audit-logs`
- `/notifications`
- `/settings`

## Purpose
This frontend exists to make the backend project easier for clients to understand visually. It is intentionally optimized for:
- portfolio screenshots
- Upwork service/portfolio use
- product-style SaaS demos

## Run
```bash
npm install
npm run dev
```
